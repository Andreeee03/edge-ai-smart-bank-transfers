INTERPRETATION GUIDE
------------------------------------------------------------------------
1) If raw_equal is 100%, batch padding/batch size is not causing the observed outputs on these records.
2) If raw_prediction itself is degenerate, the parser did not create the degeneration; it came from model generation.
3) If raw_prediction looks correct but predicted_alternatives is wrong/empty, the parser is the problem for that record.
4) full_decoded_sequence lets you verify that continuation slicing starts after the complete prompt.
5) hit_max_new_tokens_without_eos=True on repetitive outputs is evidence that the model entered a loop and never emitted EOS.
